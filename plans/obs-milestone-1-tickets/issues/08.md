## Parent

[Preserve scene UUID and canvas identity across public tools and batches](https://github.com/dearlordylord/obs-mcp/issues/9)

## What to build

Single calls and supported batches select the same intended program scene by stable UUID.

## Acceptance criteria

- [ ] Accept and preserve sceneUuid in ordinary program-scene selection and corresponding batch items; preserve existing resource contracts and document locator applicability.
- [ ] Verify UUID-only selection, name compatibility and request-specific invalid combinations against renamed or ambiguous fixture scenes.
- [ ] Check both outgoing identity and actual selected scene; extend controlled batch behavior only as needed and reuse focused protocol tests.
- [ ] Preserve batch order, capability policy, batch-only Sleep and truthful batch failure/no-replay behavior.
- [ ] Update schemas/documentation and retire the matching parity finding.
- [ ] Return truthful identity for UUID-only calls; do not fabricate a scene name or discard the supplied locator in single or batch results.
