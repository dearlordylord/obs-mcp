## What to build

CI verifies the milestone's actual installed workflow under documented defaults and explicit opt-ins.

## Acceptance criteria

- [ ] Extend the existing Node compatibility matrix and package-smoke workflow to run inspection, scene mutation/readback, audio, recording and screenshot baselines plus all completed selector, settings, native-image and fault scenarios against controlled OBS, including timeout/disconnect and lifecycle cleanup.
- [ ] Exercise normal startup defaults separately from the explicit all-toolsets configuration; assert relevant behavior/capabilities rather than a minimum tool count.
- [ ] Record source, lockfile, package identity, tarball digest and timeout configuration with each result.
- [ ] Require existing quality gates and detect current dependency/runtime regressions; preserve historical baseline attribution.
- [ ] Fail if any required workflow is pending, skipped as fixture-unimplemented or contradicted by observed state; keep real OBS outside deterministic CI.
