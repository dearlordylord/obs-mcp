## Parent

[Return native MCP images and define remote screenshot save semantics](https://github.com/dearlordylord/obs-mcp/issues/11)

## What to build

A screenshot tool returns complete native MCP image content with compatible metadata.

## Acceptance criteria

- [ ] Return native image tool content with accurate MIME type and complete decodable bytes under the recorded compatibility contract.
- [ ] Through installed MCP verify decoded content/dimensions where applicable, malformed or truncated OBS image responses, payload bounds, capture failures and capability/toolset restrictions.
- [ ] Preserve latest-screenshot metadata correlation, ownership and bounded lifetime; reuse existing HTTP/resource tests and avoid a second retention surface.
- [ ] Keep supported formats explicit; investigate expansion only against a demonstrated supported format and record the evidence/disposition.
- [ ] Document the result contract; controlled images do not count as real-client visual acceptance.
- [ ] Return native image bytes exactly matching the validated capture; an invalid capture must not replace latest-screenshot metadata.
