## What to build

Explicit output settings access preserves permitted kind-specific nested configuration.

## Acceptance criteria

- [ ] Carry the recorded bounded settings contract through output read/write APIs without silently dropping permitted encoder/output values.
- [ ] Verify nested read/update/readback and typed convenience compatibility from installed MCP against actual fixture state.
- [ ] Enforce output-specific opt-in/sensitive-value exclusions and reject disallowed writes truthfully.
- [ ] Document and verify the official write semantics, limits, unavailable capability and OBS failure behavior.
- [ ] Reuse shared settings validation where appropriate without broadening input-settings or raw-request scope.
- [ ] Apply recursive value limits and sensitive-field rules on both reads and writes, including nested arrays/objects; excluded data is explicitly marked rather than described as lossless.
